# Improve UX learnings

## Reusable patterns

- Autocomplete overlays opened by typing should immediately own focus, expose the
  active option, and dismiss on selection, Escape, or outside click.
- Compact settings controls need a visible label and effect summary; a section heading
  alone is not enough once several controls stack together.
- Terminal workspaces scan faster when session navigation has a stable side rail and
  warnings appear above the raw buffer instead of masquerading as terminal output.
