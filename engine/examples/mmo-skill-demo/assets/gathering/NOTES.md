# Gathering Art Notes

Runtime gathering node sprites live here. Source archives stay under `./assets/source/craftpix/`.

This set gives gatherables a readable material identity instead of one generic sprite per skill:

- Lumber nodes use distinct pine, birch, oak, ghostwood, and world-tree silhouettes.
- Mining, quarrying, and gemology nodes use separate rock and crystal families.
- Foraging, crops, spores, sap, fish, dredge, and salvage nodes use smaller plants, mushrooms, water patches, and prop reads.
