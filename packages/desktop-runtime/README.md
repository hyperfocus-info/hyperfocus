# Desktop runtime

Small, framework-neutral primitives for applications that use a local server and the system browser as their desktop surface.

It provides custom-protocol target parsing, file-or-folder launch resolution, last-client shutdown leases, and opt-in update checks. Update sources are injected by consumers; the package does not assume a release host or install updates without an explicit consumer action.
