# Three Arena Asset Notes

Assets are kept game-local.

- Source archives and unpacked originals: `assets/source/`
- Curated runtime-friendly set: `assets/usable/`
- Usable manifest: `assets/usable/assets-manifest.json`
- Fallback texture manifest: `assets/usable/fallbacks/fallback-texture-manifest.json`

## Availability

Kenney packs downloaded and unpacked successfully. The curated set includes FBX character rig and animation files, PNG skins, GLB props, GLB environment pieces, and PNG color maps.

Craftpix cookies were not present at `./.local/craftpix/cookies.txt`. The public Craftpix endpoint still resolved and downloaded successfully, so the full source archive and nested packs are available. A fallback texture manifest is included only as a backup path.

Additional local packs were imported into `assets/source/imported/` and curated into `assets/usable/` for runtime scenery, collectibles, weapon props, and optional animation metadata.
