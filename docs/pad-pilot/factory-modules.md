# Factory Modules

Stock modules currently shipped with PadPilot.

Canonical IDs, versions, entry paths, and capability grants live in
`apps/pad-pilot/utils/factory-modules.ts`. `bun run generate:factory-modules` produces the
native catalog; the UI, browser host, and initial application state consume the
same source directly.

| Module | Quick summary |
| --- | --- |
| Analyzer | Capture-aware pitch/key analyzer with harmonic grouping, per-note confidence, persistent pitch correction, and MIDI drag/save. |
| Editor | Controller-to-action binding editor with persisted per-profile mappings for MIDI notes, validated keyboard or DAW shortcuts, and profile switching through the public producer-action capabilities. |

Public `FxChainState` includes two tempo-syncable LFOs and up to 16 fixed-capacity parameter routes. Parallel chains use rendered-count compensation so transparent racks preserve unity; leaving an FX-capable Module ramps the graph to dry before it becomes quiescent. Reverse uses preallocated capture/playback windows, Tremolo performs native amplitude modulation, Saturation supplies four transfer characters, Delay exposes filter/width/saturation/character controls, and all three EQ band frequencies are adjustable. Convolver uses a per-node, 25 MiB-capped managed impulse response with deduplicated cache-healing bytes bounded to 32 MiB aggregate and a truthful Blend control. Phaser uses a fixed-stage all-pass network, Rotary Speaker models separate horn/drum rotation with amplitude and Doppler modulation, and Pitch Drift uses bounded variable-delay pitch modulation. |
